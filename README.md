# Project page: Does machine learning on Raman spectra still need preprocessing?

Single-page site for the paper by Mario Koddenbrock, Christoph Lange and Erik Rodner. It contains:

- **Recipe explorer.** All 26 preprocessing recipes, precomputed on 100 synthetic spectra and on 100 real spectra from three benchmark datasets. "Generate new" draws another precomputed spectrum. Each recipe shows its result in the benchmark.
- **Main paper content.** All tables and figures of the main paper:
  - Figs. 1 and 4 and Table 4 are redrawn as interactive charts.
  - Figs. 2, 3, 5 and 6 are the paper's own figures.
  - Tables 1, 2, 3, 5 and 6 are HTML tables.

Plain HTML, CSS and JavaScript with D3 from a CDN. There is no build step.

## View locally

```bash
python -m http.server 8000   # then open http://localhost:8000
```

The page loads its data with `fetch`, so opening `index.html` directly from disk does not work.

## Rebuild the data

The site is static; these scripts produced what is in `data/` and `assets/figures/`.

```bash
# recipe outputs (needs raman-bench>=1.6.0 and a local copy of the RamanBench Hugging Face mirror)
python tools/build_spectra.py --mirror <RamanBench mirror snapshot>
# paper numbers: Tables 2, 4, 5, 6 parsed from the paper's .tex, Figs. 1 and 4 from the analysis CSVs
python tools/build_paper_data.py --paper <paper repo> --native <analysis dir>/study1_GSB/native
# paper figures as SVG (poppler's pdftocairo)
bash tools/build_figures.sh <paper repo>
# checks; the comparisons with the paper run when PAPER_DIR is set
PAPER_DIR=<paper repo> python -m pytest tests -q
```

Recipes that learn from the data (MSC, EMSC, standard scaling, GCU, LVSE and the recipes containing them) are fitted on each whole set: the 100 synthetic spectra, or every spectrum of a real dataset.

## Data

- **Synthetic spectra:** three components with pseudo-Voigt bands, plus a fluorescence background, multiplicative scatter, an offset, noise and cosmic-ray spikes. Generated by `tools/build_spectra.py` with a fixed seed.
- **Real spectra:** `bioprocess_analytes_kaiser` (doi:10.1016/j.saa.2025.125861), `fuel_handheld` (doi:10.1021/acs.energyfuels.9b02944) and `adenine_colloidal_gold` (doi:10.1021/acs.analchem.9b05658). All three are CC BY 4.0 and are taken from RamanBench.

Code, configurations and scores of the study: https://github.com/ml-lab-htw/RamanPreprocessing
